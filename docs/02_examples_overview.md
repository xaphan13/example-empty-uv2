# Обзор примеров и как их запускать

## Как запускать примеры

Каждый пример можно запускать отдельно через модуль или через главный скрипт `main.py`.

### Через главный скрипт

Запуск всех примеров последовательно:
```bash
python main.py
```

### Через конкретные модули

Каждый пример имеет свою точку входа:

#### Многопроцессорные приложения
```bash
python -m ex_work_process.main_work_process
```

#### Простой async/await
```bash
python -m ex_async_simple.main_async_simple
```

#### Async context managers
```bash
python -m ex_async_with.main_async_with
```

#### Async генераторы и итераторы
```bash
python -m ex_async_gen_iter.main_async_gen_iter
```

#### Метаклассы
```bash
python -m ex_metaclass.main_metaclass
```

#### Работа с библиотеками
```bash
python -m ex_library.main_library
```

#### Работа с ZIP архивами
```bash
python -m ex_file_zip.main_file
```

#### Алгоритмические задачи
```bash
python -m ex_code_war.main_code_war
```

#### Различные другие примеры
```bash
python -m ex_all_others.main_others
```

## Краткое описание каждого примера

### ex_work_process
Демонстрирует различные подходы к многопроцессорному программированию в Python:
- Прямое использование `multiprocessing.Process`
- Использование `multiprocessing.Pool`
- Использование `concurrent.futures.ProcessPoolExecutor`
- Комбинированные пулы процессов

### ex_async_simple
Примеры базового асинхронного программирования:
- Простые корутины с `async/await`
- Использование `asyncio.gather()` для запуска нескольких корутин
- Работа с контекстными переменными в асинхронном контексте

### ex_async_with
Примеры использования асинхронных контекст-менеджеров:
- Создание и использование собственных async context managers
- Работа с асинхронными ресурсами (например, сетевые соединения)

### ex_async_gen_iter
Асинхронные генераторы и итераторы:
- Создание асинхронных генераторов с `async yield`
- Использование `async for` для итерации по асинхронным последовательностям
- Обработка исключений в асинхронных генераторах

### ex_metaclass
Создание и использование метаклассов:
- Пользовательские метаклассы для модификации создания классов
- Метаклассы, которые вызывают себя多次
- Переопределение специальных методов через метаклассы
- Переменные, определенные внутри функций в контексте метаклассов

### ex_library
Работа с внешними библиотеками:
- Потоковая обработка данных с использованием `streamz`
- Создание пользовательских потоковых преобразований
- Примеры интеграции различных потоковых операций

### ex_file_zip
Работа с ZIP архивами без создания временных файлов:
- Создание ZIP архивов в памяти
- Чтение и извлечение файлов из ZIP архивов
- Обработка ZIP архивов без промежуточного сохранения на диск

### ex_code_war
Алгоритмические задачи и кодварс-стильные примеры:
- Проверка правильности скобочных последовательностей
- Разделение строк по различным критериям
- Демонстрация операций с `__iadd__` и связанными методами

### ex_all_others
Различные полезные примеры и техники:
- Работа с ловушками и обработкой исключений (`trap_task`)
- Использование SSH туннелей (`ssh1`)
- Примеры работы с байт-кодом и дисассемблированием (`dis_module`, `dis_async_await`)
- Форматированный вывод в терминал с `rich`
- Демонстрация замыканий и их применения (`closure_func`)
- Глубокое копирование объектов (`deep_copy_example`)
- Работа с хешированием и проверкой целостности (`sobes11`)
- Различные утилиты и вспомогательные функции (`others_11`, `my_module`)
- Работа с глобальными переменными и модулями (`glob_mod`)
- Работа с диспатчерами и обработчиками событий

## Требования к запуску

Для запуска всех примеров необходимы:
- Python 3.12 или выше
- Установленные зависимости из `pyproject.toml` (выполнить `uv sync`)
- Для некоторых примеров может потребоваться доступ к сети или файловой системе

## Советы по изучению

Каждый пример содержит комментарии и структурированный код, который иллюстрирует конкретную концепцию. Рекомендуется:
1. Запускать пример и наблюдать вывод
2. Изучать исходный код, обращая внимание на комментарии
3. Модифицировать примеры для лучшего понимания работы механизмов
4. Сравнивать růзные подходы к решению аналогичных задач в разных директориях
